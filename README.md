# DeepSeek 桌宠

这是一个 Windows 桌面学习监督宠物，名字为 Deepseek。它读取工作区里的 `学习计划_当前.md`，显示 P0 任务，并把勾选的完成项写回状态列。每次回写保留一份 `.md.bak` 备份；不会自动判定你的任务是否真的完成。

## 如何安装项目环境

1. 第一次打开项目，输入`uv sync`安装必要的依赖环境
2. 输入`uv run python check_assets.py --root .` -> 看到`扫描0个md,跳过0个 /n OK：全部完成`,视为依赖安装完成

## 启动

在本目录打开 PowerShell：

```powershell
python -m pip install -r requirements.txt
python main.py
```

也可以双击 `start_pet.bat`。首次需要 Python 3.10+，缺少依赖时脚本自动安装；本机已安装并验证。运行后没有常驻命令行窗口，重复启动不会出现多个宠物。

- 启动使用正常动画，3 秒后提示当前 P0 的前 3 项；欢迎提示不计入忽略次数。暂停提醒时不弹欢迎提示。
- 提醒间隔固定为 30 分钟。生气必须同时满足：累计 60 分钟没有完成记录，且忽略过一次提醒。详细规则见下表。
- 拖动改变位置，左键打开任务面板，右键打开菜单。
- 「暂停提醒」跨重启保留；「显示桌宠」控制显示或隐藏；「退出桌宠」结束进程。隐藏后可从 Windows 托盘恢复。
- 默认启用 Windows 当前用户的登录自启；任务面板和右键菜单都能关闭。位置写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的 `DeepseekStudyPet`，不需要管理员权限。
- 全部完成后不再自动提醒。任务属于本周 P0，不是人为编造的每日新任务。

## 正常与生气的场景规则

| 场景 | 动画与行为 |
| --- | --- |
| 启动、日常陪伴、查看任务、拖动 | 正常动画；已经生气时，点击、查看或拖动不会解除生气 |
| 每隔 30 分钟，仍有未完成任务 | 正常动画和温柔提醒 |
| 提醒出现后 60 秒未回应 | 记一次忽略；关闭气泡不算回应 |
| 累计 60 分钟无完成记录，并且已经忽略过一次 | 切换生气动画，显示一次催促文案 |
| 开启陪聊后每 15 分钟（不要求有未完成任务） | 正常动画，说一句与任务无关的日常话，见下方「主动陪聊」 |
| 生气后仍未回应 | 持续循环生气动画；催促气泡显示 5 分钟后自动收起，不再反复弹新气泡 |
| 生气满 30 分钟 | **自动消气**：回到正常动画和 30 分钟提醒周期，清零连续忽略次数，说一句「气消了」 |
| 点击「我在做」 | 立即正常，清零连续忽略次数，60 分钟内不催 |
| 点击「稍后提醒」 | 立即正常，清零连续忽略次数，30 分钟后再提醒 |
| 完成任意一项任务 | 立即正常，清零忽略次数和无进展时长，给一句肯定 |
| 全部完成 | 正常陪伴，停止自动提醒与监督计时 |

气泡和任务面板均提供两个回应按钮。「回应」仅指上述按钮或记录完成。单纯点击、拖动、打开清单和手动查看提醒均不清零忽略次数，也不算完成。新增、改名或删除任务不算完成；只有已有任务从未完成变为已完成才重置无进展时长。外部修改学习计划每 5 秒检查一次，面板保存即时生效。

只累计桌宠显示、提醒开启、存在未完成任务且 Windows 未锁定或睡眠的时间。不读取当前应用、键盘或鼠标活动。

暂停、隐藏、锁屏、睡眠或退出时，停止计时，取消等待回应的提醒，清零连续忽略次数并恢复正常；保留已累计的无进展时长。恢复后重新等待 30 分钟再温柔提醒，不因离线时长触发生气。无进展时长每 30 秒保存一次，正常退出立即保存；强制终止最多丢失约 30 秒。旧版离线计时不迁移。

「我在做」后的 60 分钟仍累计无进展时长，但不发自动提醒。到期先温柔提醒，此后忽略一次就会再次生气。期间发生暂停等中断时，以恢复后的 30 分钟规则为准。

验收时间线（均为有效监督时间）：启动 → 第 30 分钟温柔提醒 → 第 31 分钟记一次忽略 → 第 60 分钟无进展门槛达成，直接切换生气动画（第二次温柔提醒不再发出）。

生气要同时满足「无进展 ≥ 60 分钟」和「忽略 ≥ 1 次」，谁后到以谁为准：从零开始的时间线里 60 分钟先到，生气出现在第 60 分钟；而刚点过「我在做」或暂停恢复之后，无进展时长早已满足，于是下一次提醒被忽略的瞬间就生气，不再多等一个 30 分钟周期。

**生气不是死胡同：生气满 30 分钟自动消气**，回到正常动画与 30 分钟提醒周期。这个出口是必须的——无进展时长只在「完成一项任务」时清零，一旦它超过 60 分钟，这个门槛就永远成立，宠物会一直板着脸，连温和提醒也一起停掉（生气期间不发新提醒）。所以长期不勾任务时的节奏是：生气 30 分钟 → 自动消气 → 约 31 分钟后再次生气，循环往复；想彻底结束循环，勾掉一项任务即可。

## 主动陪聊（每 15 分钟）

右键菜单和托盘菜单里的「每 15 分钟陪聊」是一个独立开关，**默认关闭**。开启后桌宠每隔 15 分钟主动说一句与任务无关的话，让桌面上的存在感更像陪伴，而不是只有监督。

| 对话类型 | 说什么 |
| --- | --- |
| 日常闲聊 `daily` | 随口问问今天过得怎么样、外面的天气、吃了没 |
| 学习总结 `summary` | 回顾完成了多少、还剩多少、陪了多久；只回顾，不催促 |
| 生活关怀 `care` | 喝水、起身活动、看远处、坐姿、颈椎、手腕、呼吸；**深夜和凌晨自动改说该睡了** |
| 傲娇吐槽 `tease` | 撒娇或轻轻吐槽用户太安静 |
| 碎碎念 `musing` | 它自己关于学习、关于当桌宠、关于模型的小感想 |
| 小灵感 `spark` | 一条很小的学习方法，或一个轻松的小问题 |

六种类型按固定顺序轮换，同一类型内部随机选句，所以语气不会连着重复。每种类型有 10 条左右本地文案（深夜关怀 6 条），内容也不会很快重复。

`care` 还按时段分流：白天说起身、喝水、看远处、坐姿、颈椎手腕；**深夜和凌晨改说该睡了**——这个点劝人「起来走两步」是不对的。

- 「现在说一句」可以立刻试听一条，不必等 15 分钟。
- **陪聊与监督完全隔离**：不计入忽略次数、不占用 60 秒回应窗口、不影响生气判定。
- 开口的硬门槛只有三个：**开着陪聊、桌宠可见、Windows 未锁定**。不要求有未完成任务，也不受「暂停提醒」影响；这三个条件里任何一个不满足，计时归零重来。
- 气泡被占用（提醒或催促使气泡还在屏幕上）时**只跳过这一次，不重置计时**——攒着，等气泡空了立刻补上。所以在生气或等待回应期间陪聊只是安静地等，不会永久失效。
- 生气时开口会换成「傲娇吐槽」的语气：正在闹脾气，说什么都像撒娇。
- 没有 API key 时使用本地文案池；打开「使用 API 生成文案」后改由 DeepSeek 生成，网络失败自动回落到本地文案。请求只带未完成任务标题和进度数字，不发送整个学习计划。

## API key 配置

1. 双击 `configure_api.bat`，输入自己的 DeepSeek API key，输入不会显示出来。
2. 退出并重新启动桌宠，API 文案自动开启。也可在 `configure_api.py` 的 `API_KEY` 行填写后运行脚本。
3. 任务面板可关闭「使用 API 生成文案」。

key 保存在本机 `config.json`（明文，已加入 `.gitignore`）。不要提交含真实 key 的配置或脚本。脚本只更新 API 配置，保留提醒、自启和进度设置。启用 API 时只发送本次待办标题给 DeepSeek，不发送整个学习计划；网络错误自动保留本地文案，单次最长等待约 12 秒，最多每 30 秒发起一次请求。动画与计时完全由本地规则决定；API 仅替换文案，不延长回应期限，不重新打开已关闭的气泡。

## 已接入的六帧动画

- 第一张素材保存为 `assets/normal_source.png`，用于正常状态；第二张保存为 `assets/angry_source.png`，用于生气状态。
- 执行 `python prepare_animation.py` 可重建透明序列帧、播放清单和 GIF 预览。程序按上排左至右、再下排左至右切出六帧，处理绿色背景，并将人物高度与底部基线对齐。
- 正常动画：每帧 180ms，最后一帧额外停留 3000ms 后循环。
- 生气动画：每帧 180ms，最后一帧额外停留 600ms 后循环。
- 帧位于 `assets/frames/normal_00.png` 至 `normal_05.png`、`angry_00.png` 至 `angry_05.png`；播放使用原素材的表情和手部变化，固定绘制位置与大小。
- 原透明立绘 `assets/deepseek_chibi.png` 保留为托盘图标及缺失素材时的备用图，可用 `python prepare_assets.py` 重建。

## Lovart 序列帧提示词

以下保留为后续绘图模板；当前已接入用户提供的正常和生气两组素材。后续仍以 `assets/deepseek_chibi.png` 为形象基准，不重新设计角色；优先上传透明 PNG 原文件，一次生成一组，直接引用同一原文件，避免多轮绘图导致形象漂移。

```text
请对上传的这张 Deepseek 现成立绘做局部编辑，制作一组六帧动画。
这张图已经是定稿角色，不要重新设计角色，不要另画基准立绘。

锁定原图的脸型、头身比、发型、发色、蕾丝头饰、蝴蝶结、服装花纹、坐姿、尾巴位置、线条和上色风格。
默认姿势就是原图的闭眼笑、张嘴、双手在胸前。只编辑本次动作涉及的眼睛、嘴和局部肢体，尽量保留其余区域。
需要睁眼时使用蓝色瞳孔，保持原图眼睛的位置和面部比例。

本次动作：粘贴下方三个动作说明中的一个。

输出要求：
- 1536×1024，三列两行，恰好六帧；每个不可见的格子为 512×512。
- 阅读顺序为上排从左到右，再下排从左到右。
- 每格只有一个完整人物。角色大小、坐姿底部基线、身体中心及视角保持一致。
- 每格四周至少留 24 像素空白，呆毛、手、裙摆、尾巴都不能碰边或跨格。
- 第一帧和最后一帧恢复原图姿势与表情，中间帧按动作顺序连续变化。
- 所有格子背景都使用完全均匀的纯绿色 #00FF00，绿色不用于人物或衣服。
- 不绘制格线、边框、帧号、动作文字、字幕、气泡、地面阴影、光晕、运动线或漂浮装饰。
- 输出原始 PNG。
```

每次将一个动作说明填进上面的「本次动作」：

- `idle.png`：原图闭眼笑 → 眼睛半开 → 蓝色眼睛睁开 → 保持睁眼，嘴稍收成微笑 → 眼睛半闭，嘴恢复 → 原图闭眼笑。手、身体与坐姿保持原样，先验证表情变化与形象一致性。
- `click.png`：原图姿势 → 睁眼略惊讶 → 脸红，头轻偏 → 一只手举到脸旁轻挥 → 手收回，头回正 → 原图姿势。坐姿和躯干保持稳定，动作温柔、略带傲娇。
- `remind.png`：原图姿势 → 睁眼、轻皱眉、嘴抿起 → 轻鼓腮，一只手从胸前抬起 → 食指竖起作提醒，表情轻微不耐烦 → 手收回，眉眼放松 → 原图姿势。动作可爱，不凶狠。

检查重点：每张动作图确实只有六个人物；白色头饰和围裙完整；眼睛与手部有真实变化；各格角色没有忽大忽小或跨格。
